## 选型结论

### B站（P8，完整方案，主平台）
- **信息流**：`wbi/index/top/rcmd`（推荐流，30条/次）
- **搜索/主题聚合**：`wbi/search/type`（关键词）
- **播放**：durl mp4 直链原生 video（未登录 720P 够用）；登录后 DASH 走 dash.js
- **下载**：durl 直链复用现有 DownloadService
- **登录**：cookie（SESSDATA/buvid3）→ 解锁高清；实施阶段实测确认清晰度提升
- 预留 wbi 签名能力（接口当前未强制 w_rid，防收紧）

### 快手（P10，降级实验性）
- 不做 graphql 逆向
- 实现**分享链接解析**（v.kuaishou.com 短链 → 详情页提取直链）
- 需用户提供 1 条真实分享链接样本验证

### 抖音（P11，降级实验性）
- 不做 a_bogus 逆向
- 实现**分享链接/页面 URL 解析**（v.douyin.com → 详情页提取直链）
- 需用户提供 1 条真实分享链接样本验证

### 聚合（P9）
- 主数据源 = **B站搜索（关键词）**（唯一未登录可用的搜索能力）
- 快手/抖音 = 用户粘贴的分享链接解析结果并入聚合流
- 聚合器接口保持平台无关（`PlatformVideo[]`），平台数据源可插拔

## 待办（实施阶段入口条件）
